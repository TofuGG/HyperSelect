# HyperSelect

> 适用于小米澎湃系统（Xiaomi HyperOS）的全域选择器与文本菜单净化增强 Xposed 模块。

HyperSelect 深度接管 HyperOS 下的**文本选择菜单**、**系统分享面板**与**打开方式列表**，提供全局自由隐藏收纳、置顶锁定、拖拽排序与流氓入口净化，规则毫秒级即时生效，无需重启系统或目标应用。

---

## 核心特性

### 1. 文本选择菜单净化
- **屏蔽 AI 写作气泡**：彻底移除长按文字弹出菜单中最左侧突兀的小米便签“AI 写作”小圆圈。
- **左滑快速收纳**：向左滑动任意不需要的功能卡片，一键移入隐藏名单，精简菜单长度。
- **长按手柄拖拽排序**：长按卡片右侧手柄，自由调整每个菜单项的先后展示顺序。
- **毫秒级即时同步**：规则保存后系统选词条立即生效，底部支持误操作随时撤销。

### 2. 系统分享面板定制
- **置顶锁定机制**：将高频常用应用（如微信、QQ等）点击「置顶」固定在面板首位，绝不被低频临时应用下沉冲乱。
- **随系统习惯自然流动**：未置顶的常规应用不写死顺序，完全交还 Android 原生使用习惯预测算法动态排列。
- **手柄精准调序**：已置顶的应用可长按手柄自由微调彼此间的先后位次。
- **左滑一键收纳**：滑动隐藏低频骚扰或极少使用的应用，大幅精简分享弹窗。

### 3. 打开方式选择器增强
- **全格式全组件探查**：彻底修复原生 Intent 匹配遗漏问题，完整覆盖网页、音视频、文档（PDF/Office）、APK/APKS/ZIP 等 380+ 组件。
- **置顶锁定与动态流动**：常用浏览器或解压工具锁定在最前排，其余常规应用随文件类型和使用习惯自然浮动。
- **深度拦截与名单收纳**：向左滑动隐藏非必要的文件处理入口，净化打开方式弹窗。

### 4. 极致交互与系统级体验
- **HyperOS 原生设计语言**：纯净无感的设计风格，大圆角卡片、平滑回弹微动效与触感震动反馈。
- **即搜即改**：支持全列表即时搜索，过滤状态下依然支持完整的置顶、收纳与手势撤销。
- **开箱即用（静态作用域）**：模块声明 `staticScope=true`，LSPosed 激活后自动锁定系统框架与分享选择器，无需手动勾选应用。

## 原理简析

1. **选词气泡与搜索项拦截**：
   在 `system_server` 中，对外部调用方伪装小米笔记（`com.miui.notes`）查询版本号，使编辑器组件自适应收起 AI 气泡；并在 `resolveIntent` 中精准过滤指向 `qsb://query` 的编辑器兜底搜索项。
2. **系统分享与打开方式排序接管**：
   Hook 系统 `IntentResolver` / `ChooserActivity` 以及 MIUI 专有的 `MiuiChooserGridAdapter`，基于本地规则执行双层排序（置顶项按自定义权重点阵排列，未置顶项保持系统原始 TimSort 相对顺序）。
3. **多类型深度探查与即时持久化**：
   通过复合 URI + MIME Type 全维度探测组件注册信息；配置变动毫秒级刷写进设备保护存储区（Device Encrypted Storage），Xposed 侧监听文件变动即时热更新缓存。
